## Capture boundaries

Both archives were run locally. The family preview used an isolated rendering entry, a seeded query cache, and inert server-function replacements. Network requests outside localhost were blocked in the screenshot browser. No production login, family record, generated AI response, or write to the live service was used. Rendering these screens does not verify server behavior, access controls, AI response quality, automatic memory generation, or the application's complete workflows.

The UI components and styling came from the supplied source. Preview-only changes and sample fixtures are not application changes and are not included as source code in this portfolio. The original source archives remain private. Public website fonts were unavailable during offline capture, so typography may differ slightly from hosted rendering.

Alex, the monthly reflection, and the family moment are fictional. The coach roster comes from the historical application's built-in demo dataset and is shown only in its explicitly labeled sample mode.
